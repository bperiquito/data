# 🚀 Interactive Data Analytics CV Website

An interactive online resume and portfolio designed to showcase my professional experience, skills, certifications, and projects in a modern and engaging way.

🔗 **Live Website:** https://bperiquito.github.io/data/

## 📋 About the Project

This project was created to provide a more dynamic alternative to a traditional PDF. Instead of simply listing professional information, the website offers an interactive experience where visitors can explore my background, technical skills, career history, certifications, and achievements.

The goal is to combine a clean design with accessibility and ease of navigation, making it easier for recruiters and hiring managers to learn more about me.

1. Clone the repository:


2. Open the project folder:

```bash
cd data
```

3. Open `index.html` in your browser.
